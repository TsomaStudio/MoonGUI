# MoonGUI

Лёгкий GUI-тулкит на C17 (без C++ в нашем коде). Первая платформа — Windows 11;
Linux (Wayland) и macOS — позже.

**Цели:** маленькие exe и минимальное потребление ресурсов, простой API,
корректный и красивый текст на всех письменностях, основа для видеоплеера,
аудиоплеера, игрового движка, фоторедактора и виджетов рабочего стола.

**Статус:** проектирование завершено, идёт фаза 0 (фундамент: сборка, CI, библиотека `base`).
