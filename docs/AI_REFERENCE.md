# Справка для ИИ: как писать код под MoonGUI

Статус: скелет. Разделы по подсистемам добавляются вместе с API; правило проекта —
справка обновляется в том же PR, в котором меняется API, а примеры из неё собираются в CI.

## Правила
- Язык: C17, без расширений компилятора, без C++. Идентификаторы и комментарии в коде — английский.
- Платформа: Windows 11 (первая). Платформенный код только в `src/**/platform/` и `src/base/{win32,posix}`.
- Нет глобального изменяемого состояния: всё в контексте (`moon_context`).

## Соглашения
1. Имена: функции `moon_<модуль>_<действие>`, типы `moon_<имя>` (без `_t`), макросы `MOON_<ИМЯ>`,
   значения перечислений `MOON_<ТИП>_<ЗНАЧЕНИЕ>`.
2. Ошибки: функции возвращают `moon_result` (0 — успех); значения — через выходные параметры.
   Без `errno`, `setjmp`, исключений.
3. Владение: у каждой функции создания есть парная функция уничтожения; в документации указано
   `borrowed`, `owned` или `copied`. По умолчанию строки копируются.
4. Дескрипторы: параметры создания — структура, первое поле `size`; нулевая инициализация даёт
   значения по умолчанию.
5. Типы: размеры — `size_t`, индексы и счётчики в публичном API — `uint32_t`, геометрия — `float`.
6. Запрещено: VLA; `goto` только для единого выхода с очисткой.
7. Защита от повторного включения: `#ifndef MOON_<ПУТЬ>_H`.
8. Каждая публичная функция имеет Doxygen-комментарий (назначение, параметры, владение,
   потокобезопасность, коды ошибок).
