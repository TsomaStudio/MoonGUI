# HANDOFF: как продолжить работу над MoonGUI в новом чате

Это главный источник правды о состоянии проекта; он обновляется в каждом PR. ИИ, читающий файл
в начале нового чата: прочитай его целиком, затем `docs/PROJECT_RULES.md`, затем действуй по
разделу «Что делать дальше». Большие документы целиком не читай (экономь контекст).

## Что за проект
MoonGUI: лёгкий GUI-тулкит на C17 для Windows 11 (Linux Wayland и macOS позже). Личный проект
владельца (GitHub: TsomaStudio), лицензия 0BSD. Основа для видеоплеера, аудиоплеера, игрового
движка, фоторедактора, виджетов рабочего стола. Главное: маленькие exe, минимум ресурсов,
простой API, нормальный текст на всех письменностях.

## Реестр решений (кратко)
| ID | Решение |
|---|---|
| D-01 | Retained-дерево виджетов + display list; Canvas с immediate-API |
| D-02 | 14 подсистем = CMake-цели; зависимости только вниз; платформенный код только в platform/ |
| D-03 | API на C17: типизированные generation-handles, дескрипторы с полем size, коды результата |
| D-04 | Память: внедряемый аллокатор, арены, пулы, 6 классов времени жизни; 0 аллокаций в стабильном кадре |
| D-05 | Один UI-поток, потокобезопасный `moon_post`, display list как снимок |
| D-06 | Рендер: software-эталон + D3D11 (v1); Metal и OpenGL вместе с портами |
| D-07 | Layout: measure/arrange, Stack/Grid/Dock/Scroll/Virtual, relayout boundaries, кэш измерений |
| D-08 | Виджеты: базовая структура + vtable класса, части и состояния в теме, семантика a11y в базе |
| D-09/D-14 | Текст: DirectWrite на Windows (все письменности, из C); CoreText и HarfBuzz+FreeType (dlopen) позже |
| D-10 | Собственный PAL (win32 и null в v1); SDL не используем |
| D-11 | Монорепо, vendored third_party, ADR на решения |
| D-12 | Метрики: детерминированные счётчики как жёсткие gate, время как тренд |
| D-13 | Явная регистрация классов виджетов (линкер выбрасывает неиспользуемое) |
| D-15 | Декодирование изображений на Windows через WIC; stb_image как переносимый вариант |
| D-16 | Viewport: область, куда приложение рисует само; общий D3D11 device |
| D-17 | Окна-оверлеи: без рамки, прозрачные, поверх всех, click-through, трей |
| D-18 | Ввод для игр и медиа: raw mouse, геймпады, медиаклавиши, глобальные горячие клавиши |
| D-19 | Два слоя API: простой и низкоуровневый; immediate-слой после v1 |
| D-20 | Справка для ИИ `docs/AI_REFERENCE.md`, обновляется вместе с API |

Итоги вопросов владельцу: имя MoonGUI; префикс `moon_`; лицензия 0BSD; только Windows 11
(Windows 10 и X11 исключены); Objective-C только для macOS позже; собственные меню; статическая
сборка без гарантий ABI; accessibility в 1.0: семантика и клавиатура (мосты после 1.0);
вне 1.0: вертикальный текст, мобильные и веб, HDR (wide gamut и 16-bit в v1.1).
Выпуски: v0.1 (фазы 0–3), v0.2 (4–5), v0.3 (6–7), v1.0 (8). У каждой фазы есть демо-приложение
как критерий готовности.

## Рабочие договорённости
- Процесс, язык, PR и слияния: `docs/PROJECT_RULES.md`.
- **Токен.** Владелец вставляет токен GitHub в начале чата (в репозиторий он не записывается).
  Использовать только для TsomaStudio/MoonGUI; не печатать в выводе, не писать в файлы, коммиты
  и логи; для push использовать `git -c http.extraheader=...`, не сохраняя в `.git/config`.
  Репозиторий публичный: клонируется без токена, токен нужен только для записи.
- **Контекст чата ограничен.** Один этап (или несколько мелких) за чат. В конце этапа обновить
  «Текущее состояние» и «Что делать дальше» в этом файле и закоммитить.
- После каждого этапа: сборка, тесты, предупреждения, проверка памяти, документация, итог.
